# قالب فروشگاه اینترنتی (Next.js)

قالب فرانت‌اند فروشگاه خرده‌فروشی با الهام از ساختار دیجی‌کالا؛ راست‌چین، فارسی، ریسپانسیو، سئو شده و آماده دپلوی روی Vercel.

## تکنولوژی‌ها

- **Next.js 16** (App Router، React Server Components، SSG)
- **React 19** + **TypeScript**
- **Tailwind CSS 4**
- **lucide-react** برای آیکون‌ها (فقط آیکون‌های استفاده‌شده در باندل قرار می‌گیرند)
- فونت **وزیرمتن** به صورت self-host (بدون وابستگی به CDN خارجی)

بدون کتابخانه سنگین اسلایدر، انیمیشن یا سه‌بعدی؛ افکت‌های سه‌بعدی (مکعب چرخان، Tilt بنرها و گالری، تصویر شناور اسلایدر) فقط با CSS ساخته شده‌اند.

## اجرا

```bash
npm install
npm run dev     # http://localhost:3123
npm run build   # بیلد production
```

راهنمای کامل دپلوی: [DEPLOY.md](./DEPLOY.md)

## صفحات

| مسیر | توضیح |
| --- | --- |
| `/` | صفحه اصلی: استوری، اسلایدر، دسترسی سریع، شگفت‌انگیز با تایمر، بنرها، دسته‌بندی‌ها، پیشنهاد سلیقه‌ای، برندها، داغ‌ترین‌ها، پرفروش‌ترین‌ها، خواندنی‌ها |
| `/category/[slug]` | لیست محصولات با فیلتر (برند، موجودی، ارسال سریع، تخفیف) و مرتب‌سازی؛ فیلتر موبایل به صورت Bottom Sheet |
| `/product/[slug]` | جزئیات محصول: گالری، انتخاب رنگ، باکس خرید، مشخصات، دیدگاه‌ها، کالاهای مشابه، نوار خرید چسبان در موبایل |
| `/incredible-offers` | پیشنهادهای شگفت‌انگیز |
| `/search?q=` | جستجو (همراه با پیشنهاد زنده در هدر) |
| `/cart` | سبد خرید (ذخیره در localStorage)، نوار پیشرفت ارسال رایگان |
| `/login` | ورود با شماره موبایل و کد تایید (فقط رابط کاربری) |
| `/categories` | همه دسته‌ها (مخصوص منوی پایین موبایل) |

## سئو

- Metadata کامل برای هر صفحه (title، description، canonical، Open Graph، Twitter)
- داده ساختاریافته JSON-LD: `Organization`، `WebSite + SearchAction`، `Product + Offer + AggregateRating`، `BreadcrumbList`، `ItemList`
- `sitemap.xml`، `robots.txt` و `manifest.webmanifest` به صورت خودکار
- صفحات محصول و دسته‌بندی به صورت استاتیک (SSG) ساخته می‌شوند
- `lang="fa"` و `dir="rtl"`، ساختار سرتیترهای معنایی و برچسب‌های دسترس‌پذیری

## شخصی‌سازی برای فروشگاه خودتان

### ۱. نام، توضیحات و رنگ‌ها

فایل `src/config/site.ts` را باز کنید. چند preset آماده وجود دارد:

```ts
const activePreset: keyof typeof presets = "general";
// گزینه‌ها: "general" | "jewelry" | "mobile" | "fashion" | "grocery"
```

با تغییر این مقدار، نام فروشگاه، شعار، کلمات کلیدی سئو و رنگ برند (دکمه‌ها، بج‌ها، نوار شگفت‌انگیز) در کل سایت عوض می‌شود. برای ساخت هویت جدید یک preset اضافه کنید. شماره تماس، آدرس، شبکه‌های اجتماعی و حد ارسال رایگان هم در همین فایل هستند.

> آیکون تب مرورگر در `src/app/icon.svg` است؛ رنگ آن را هم با رنگ برند هماهنگ کنید.

### ۲. محصولات و دسته‌ها

| فایل | محتوا |
| --- | --- |
| `src/data/categories.ts` | دسته‌ها، زیردسته‌های مگامنو، آیکون و رنگ پس‌زمینه |
| `src/data/products.ts` | محصولات (قیمت به تومان، درصد تخفیف، موجودی، مشخصات، رنگ‌ها) |
| `src/data/content.ts` | اسلایدهای اصلی، بنرها، استوری‌ها، برندها و مقالات |

برای اتصال به بک‌اند، کافی است توابع `getProduct`، `byCategory` و ... را در `src/data/products.ts` با `fetch` به API خودتان جایگزین کنید؛ کامپوننت‌ها تغییری نمی‌خواهند.

### ۳. تصاویر

تصاویر نمونه از Unsplash هستند. اگر تصاویر را روی دامنه دیگری (مثلاً CDN یا سرور خودتان) دارید، دامنه را در `next.config.ts` بخش `images.remotePatterns` اضافه کنید، یا فایل‌ها را در پوشه `public` قرار دهید.

## ساختار پوشه‌ها

```
src/
├─ app/            صفحات، layout، sitemap، robots، manifest
├─ components/
│  ├─ layout/      هدر، مگامنو، جستجو، فوتر، منوی موبایل
│  ├─ home/        بخش‌های صفحه اصلی
│  ├─ product/     کارت، کاروسل، گالری، لیست و فیلتر
│  ├─ cart/ auth/  سبد خرید و ورود
│  ├─ seo/         JSON-LD
│  └─ ui/          اجزای پایه (قیمت، لوگو، Tilt، ...)
├─ config/site.ts  تنظیمات فروشگاه
├─ context/        state سبد خرید
├─ data/           داده‌های نمونه
└─ lib/            توابع کمکی (فرمت قیمت و اعداد فارسی)
```
